# راهنمای انتقال به وردپرس/ووکامرس

## نکتهٔ صادقانهٔ مهم

این پروژه یک اپلیکیشن React/Vite (Single Page Application) است. **هیچ ابزاری نمی‌تواند آن را با یک کلیک به قالب وردپرس تبدیل کند** — این دو فناوری معماری کاملاً متفاوتی دارند. آنچه واقعی و قابل‌انجام است:

## مسیر واقعی: خروجی گرفتن از کاتالوگ محصولات

پروژه از قبل دو تابع آماده برای این کار دارد (`src/lib/store.ts`):

- `productsToCSV(products)` → فایل CSV سازگار با وارد‌کنندهٔ محصول ووکامرس
- `productsToWooJSON(products)` → همان داده در قالب JSON با دسته‌بندی تودرتو (پوشاک/کفش ← مردانه/زنانه ← زیردسته)، تصاویر، سایزها و برند

### گام‌به‌گام

1. از پنل مدیریت (`/admin` ← تب «محصولات») روی دکمهٔ خروجی CSV بزنید.
2. در وردپرس، افزونهٔ **WooCommerce** را نصب کنید.
3. از مسیر `ووکامرس ← محصولات ← درون‌ریزی` فایل CSV را وارد کنید.
4. نگاشت ستون‌ها: `categories` به‌صورت خودکار به‌عنوان دسته‌بندی تودرتوی ووکامرس (والد/فرزند) شناسایی می‌شود چون داده از قبل به همین شکل صادر می‌شود.
5. فیلدهای اختصاصی (برند، جنسیت، سایزها) به‌صورت **ویژگی محصول (Attribute)** در ووکامرس وارد می‌شوند — پس از درون‌ریزی، این‌ها را در بخش «ویژگی‌ها» بررسی و در صورت نیاز به فیلتر قابل‌کلیک تبدیل کنید.

## مسیر جایگزین (حرفه‌ای‌تر، برای آینده): معماری Headless

اگر می‌خواهید طراحی و افکت‌های فعلی (ترنزیشن‌ها، منوی مگا، تم رنگی) را نگه دارید ولی مدیریت محتوا را به وردپرس بسپارید:

1. یک نصب وردپرس + ووکامرس راه‌اندازی کنید (فقط به‌عنوان بانک اطلاعاتی/پنل مدیریت محصول و سفارش).
2. در `src/lib/store.ts`، بجای فراخوانی‌های Supabase، از **WooCommerce REST API** استفاده کنید — چون تمام فراخوانی‌های داده از قبل داخل همین یک فایل جمع شده‌اند (نه پخش‌شده در کل کد)، این تغییر فقط همین فایل را تحت تأثیر قرار می‌دهد، نه کل رابط کاربری.
3. فرانت‌اند فعلی (همین ظاهر، همین انیمیشن‌ها) بدون تغییر باقی می‌ماند؛ فقط منبع داده عوض می‌شود.

این مسیر دوم واقعاً «وردپرس + طراحی فعلی» را همزمان می‌دهد — نه فقط CSV.

## دامنه و هاست اختصاصی

هر دو مسیر بالا با دامنه و هاست اختصاصی خودتان کاملاً سازگارند:
- مسیر اول (فقط انتقال کاتالوگ): دامنه را مستقیم روی هاست وردپرس بیندازید.
- مسیر دوم (Headless): دامنه اصلی روی هاست فرانت‌اند (Vite build)، و وردپرس روی یک ساب‌دامین مثل `admin.originally.ir` یا `wp.originally.ir` به‌عنوان بک‌اند مدیریتی اجرا شود.
