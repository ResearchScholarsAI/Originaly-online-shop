# Originaly — فروشگاه آنلاین فارسی

فروشگاه راست‌چین کفش و پوشاک با تم **Obsidian Aurora** و صفحات محصول، فروشگاه، سبد خرید، مدیریت کاتالوگ و دستیار فروش فارسی.

## اجرا و آزمون

```bash
npm ci
npm run dev
npm test
npm run typecheck
npm run build:dev
npm run package:wordpress
```

Node.js 22 لازم است. برای production از PostgreSQL پایدار، HTTPS، backup و secrets سروری واقعی استفاده کنید؛ PGlite فقط برای توسعه/آزمون است. `.env.example` صرفاً placeholder دارد.

`npm test` شامل تست‌های app-data، auth و قرارداد WooCommerce است. تست‌های platform/Grok که به فایل‌های مخفی runtime وابسته‌اند در `npm run test:platform-template` جدا هستند.

## وضعیت کاتالوگ

- **۲۹ محصول** دارای قیمت، موجودی و یک سایز بررسی‌شده، در گروه آمادهٔ خرید قرار می‌گیرند.
- **۴۳ محصول legacy** از فهرست قبلی حذف نمی‌شوند: در کاتالوگ و در صفحهٔ اصلی با برچسب «درحال‌بازبینی · ناموجود» دیده می‌شوند. برای آن‌ها قیمت فعال صفر، موجودی صفر، و سایز/برند/جزئیات قدیمی از API عمومی پنهان است.
- در صفحهٔ محصول legacy توضیح داده می‌شود که نام/مدل و مشخصات هنوز نیازمند تأیید مالک‌اند؛ هیچ قیمت یا اندازهٔ قدیمی به مشتری نمایش داده نمی‌شود.
- سفارش سمت‌سرور فقط زمانی پذیرفته می‌شود که محصول `available`، موجودی مثبت، قیمت معتبر و دقیقاً یک سایز داشته باشد؛ دیتابیس مجدداً مرجع است و موجودی اتمیک کنترل می‌شود.
- دستیار محصولات تأییدشده را برای خرید پیشنهاد می‌دهد و موارد legacy را فقط به‌عنوان ناموجود/درحال‌بازبینی معرفی می‌کند.

## خرید و خدمات

- ارسال در محاسبهٔ فروشگاه پس‌کرایه است؛ اپراتور و مبلغ حمل را مالک باید نهایی کند.
- OTP واقعی تا اتصال و آزمون سرویس پیامکی فعال نیست؛ کد آزمایشی فقط در `NODE_ENV=development` یا `test` نمایش داده می‌شود.
- پرداخت آنلاین/زرین‌پال و callback/verify واقعی هنوز متصل نیست؛ سفارش بدون روش پرداخت فعال ثبت نمی‌شود. هیچ شمارهٔ بانکی ساختگی وجود ندارد.
- مدیر اولیه فقط با allowlist سروری `HQ_ADMIN_EMAILS` و bootstrap تراکنشی یک‌باره فعال می‌شود؛ جزئیات در `docs/ADMIN_ACCESS.md` است.

## WordPress و WooCommerce

این پروژهٔ React به‌تنهایی پوستهٔ WordPress نیست. برای ساخت بستهٔ انتقال:

```bash
npm run package:wordpress
```

در `artifacts/wordpress/` قالب RTL، افزونهٔ ورود کاتالوگ، Launch Kit کامل و CSV بازبینی ساخته می‌شوند. محصولات تأییدشده به‌صورت Draft وارد می‌شوند؛ ۴۳ مورد قدیمی به‌صورت منتشرشده اما بی‌قیمت و out-of-stock حفظ می‌شوند. پس از بررسی تک‌به‌تک، مالک می‌تواند قیمت روز، سایز واحد و موجودی را در WooCommerce ثبت کند. قیمت/سایز تاریخی در فایل و پنل مدیریت با برچسب تأییدنشده باقی می‌ماند و به مشتری عرضه نمی‌شود.

## امنیت و انتشار

هیچ گذرواژه، کلید پیامک، credential مدیریتی یا اطلاعات پرداخت را در Git قرار ندهید. در production احراز هویت باید به provider واقعی متصل و تست شود. هنوز دامنه/هاست WordPress به این نشست متصل نیست؛ سرویس پیامک، پرداخت، حمل، مالیات، policyهای فروش و ایمیل سفارش باید توسط مالک پیکربندی و آزمایش شوند. بستهٔ آماده به‌تنهایی به معنی فعال‌شدن فروش زنده نیست.
