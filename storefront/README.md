# Originaly (اورجینالی)

فروشگاه پوشاک و کفش اورجینال — پژوهان‌مهر، نظرآباد البرز.

هویت بصری این نسخه: **Obsidian Aurora** — زمینه گرافیتی، نور بنفش/فیروزه‌ای، کنش سبز اسیدی، شبکه سه‌بعدی و مگامنوی تو‌در‌تو.

## اجرا

```bash
npm install
npm run dev
```

## امکانات

- دسته‌بندی سه‌سطحی پوشاک / کفش → مردانه / زنانه → زیرشاخه‌ها
- مگامنو، جستجو، علاقه‌مندی، انیمیشن صفحه، کارت سه‌بعدی
- ثبت‌نام، OTP موبایل (لاگ آزمایشی تا اتصال کاوه‌نگار)
- درگاه زرین‌پال آماده (تا وارد شدن Merchant ID روی «به‌زودی»)
- پنل مشتریان + خروجی CSV پیامک/مالیات
- خروجی ووکامرس (`docs/WORDPRESS_MIGRATION.md`)
