# دسترسی امن پنل مدیریت

پنل مدیریت فروشگاه در مسیر `/admin` قرار دارد، اما هیچ لینک عمومی برای مشتریان در هدر یا منوی موبایل نمایش داده نمی‌شود. خواندن سفارش‌ها، مشتریان و خروجی ووکامرس فقط بعد از احراز هویت و تأیید `is_admin` در سمت سرور انجام می‌شود.

برای محیط واقعی، حساب مدیر را از طریق احراز هویت رسمی پروژه ایجاد کنید و پس از ورود، پرچم مدیر را فقط از طریق migration یا کنسول دیتابیس امن تنظیم کنید. هیچ نام کاربری یا رمز عبوری داخل کد، فایل ZIP یا فرانت‌اند ذخیره نشده است؛ این کار برای جلوگیری از افشای اعتبارنامه ضروری است.

پس از استقرار روی دامنه، آدرس مدیریت به شکل زیر خواهد بود:

```text
https://your-domain.example/admin
```

برای تولید آدرس اینترنتی واقعی، باید پروژه روی هاست یا سرویس استقرار شما deploy شود و دامنه/DNS به آن متصل گردد. تا قبل از آن، پیش‌نمایش همین پروژه قابل استفاده است اما URL آن موقت است.

## تنظیمات پیامک و پرداخت

`SMS_PROVIDER` را روی `kavenegar` یا `bird` قرار دهید و کلید سرویس را فقط در Environment Variables هاست ذخیره کنید. درگاه زرین‌پال نیز فقط پس از قرارگرفتن Merchant ID در محیط اجرا فعال می‌شود. در حالت بدون کلید، رابط کاربری وضعیت «به‌زودی» را صادقانه نشان می‌دهد و پرداخت جعلی انجام نمی‌دهد.

## انتقال به وردپرس/ووکامرس

خروجی JSON و CSV از خود پنل تولید می‌شود. نگاشت دسته‌های سه‌سطحی، برند، سایز، جنسیت، قیمت اصلی و قیمت تخفیف در `docs/WORDPRESS_MIGRATION.md` توضیح داده شده است.
