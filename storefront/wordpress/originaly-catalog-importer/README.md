# افزونهٔ انتقال کاتالوگ Originaly

افزونهٔ نصب‌پذیر WooCommerce برای دو هدف مستقل:

- **۲۹ کالای تأییدشده** را به‌صورت محصول سادهٔ پیش‌نویس وارد می‌کند تا مالک پس از تنظیم واحد پول، موجودی و درگاه آن‌ها را بازبینی و منتشر کند.
- **۴۳ کالای قدیمی** را حذف نمی‌کند: هرکدام با تصویر و نامِ آرشیوی، بدون قیمت فعال، با موجودی صفر و وضعیت «ناموجود · اطلاعات در حال بازبینی» منتشر می‌شود؛ مشتری می‌تواند آن‌ها را ببیند ولی سفارش ممکن نیست.

قیمت و سایز قدیمی برای این ۴۳ کالا فقط در صفحهٔ مدیر و فایل بازبینی با برچسب **تأییدنشده** دیده می‌شود. این مقادیر در قیمت محصول یا مشخصات عمومی ووکامرس ثبت نمی‌شوند.

## ساخت و نصب

از ریشهٔ پروژه اجرا کنید:

```bash
npm run package:wordpress
```

فایل `artifacts/wordpress/originaly-catalog-importer.zip` را از مسیر **افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه** نصب کنید. WooCommerce باید فعال باشد. سپس **WooCommerce ← کاتالوگ Originaly** را باز کنید.

پیش‌نمایش شامل SKU، نام، وضعیت، سایز/قیمت قابل‌عرضه و مقادیر قبلی با نشان «تأییدنشده» است. برای جلوگیری از اشتباه مبلغ، import تنها پس از تأیید واحد پول تومان اجرا می‌شود.

## ایمن‌سازی و فعال‌سازی دستی

- اقلام تأییدشده به‌صورت Draft وارد می‌شوند؛ افزونه درگاه پرداخت، تنظیم ارز، مالیات، ارسال یا سفارش آزمایشی را تغییر نمی‌دهد.
- اقلام آرشیوی با قیمت خالی و موجودی ۰ منتشر می‌شوند. افزونهٔ Originaly، نمایش out-of-stockها در کاتالوگ را فعال نگه می‌دارد تا این صفحات پنهان نشوند.
- برای هر قلم قدیمی، مالک باید نام/مدل، برند، تصویر، **یک سایز مشخص**، قیمت روز و موجودی فیزیکی را با اطلاعات فروشگاه تطبیق دهد. در ویرایشگر محصول WooCommerce فقط پس از تکمیل قیمت مثبت، موجودی مثبت و یک مقدار سایز، خرید مجاز می‌شود.
- محصول‌های variable خریدپذیر نیستند؛ محصول‌های سادهٔ دارای یک سایز استفاده شوند.
- اگر مدیر پس از import محصولی را ویرایش کند، import مجدد آن را بازنویسی نمی‌کند. SKU متعلق به محصول دیگری نیز رد می‌شود.
- افزونه خرید یا پرداخت انجام نمی‌دهد. برای حذف محصول/رسانه، اقدام دستی مالک و پشتیبان‌گیری لازم است.
