# قالب Originaly برای WordPress و WooCommerce

این پوشه یک **قالب نصب‌پذیر WordPress** است، نه نصب زندهٔ سایت. قالب رابط راست‌چین/فارسی را فراهم می‌کند و WooCommerce مسئول اصلی محصول، سبد، checkout، حساب کاربری و سفارش باقی می‌ماند.

## پیش‌نیاز

- WordPress 6.5 یا جدیدتر؛ PHP 8.0 یا جدیدتر
- افزونهٔ رسمی WooCommerce فعال
- نصب SSL روی دامنه پیش از جمع‌آوری اطلاعات مشتری/فعال‌کردن پرداخت

## ساخت ZIP قالب

از ریشهٔ پروژه اجرا کنید:

```bash
npm run package:wordpress
```

فایل خروجی در `artifacts/wordpress/originaly-theme.zip` ساخته می‌شود. در وردپرس، **نمایش ← پوسته‌ها ← افزودن پوسته ← بارگذاری پوسته** را انتخاب کنید. پس از فعال‌سازی، منوی اصلی و لوگو را از بخش مدیریت تنظیم کنید.

## محصول و checkout

- محصولات تأییدشده simple هستند و فقط یک ویژگی سایزِ غیرمتغیر دارند؛ ۴۳ قلم قدیمی نیز برای حفظ کاتالوگ با برچسب بازبینی، بدون قیمت و موجودی صفر نمایش داده می‌شوند.
- خرید کالاهای variable در این قالب مسدود شده است تا مدل چندسایزی ناخواسته وارد ویترین نشود.
- قیمت/ارز، مالیات، روش ارسال، پرداخت و سیاست مرجوعی توسط مدیر و WooCommerce تعیین می‌شوند؛ قیمت/سایز آرشیوی برای مشتری قیمت جاری نیست و محصول review تا تکمیل دادهٔ واقعی سفارش نمی‌پذیرد.
- قبل از فروش واقعی، پرداخت، callback/verify، پیامک، روش حمل، صفحه‌های سیاست، ایمیل‌های سفارش و ثبت‌نام را با تراکنش آزمایشی بررسی کنید.

برای ورودی CSV، بستهٔ محصولات در `artifacts/woocommerce-export/` و راهنمای تکمیل تصویر/URL در `docs/WORDPRESS_MIGRATION.md` قرار می‌گیرد.
